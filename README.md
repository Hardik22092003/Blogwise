# Blogwise 📝

**Blogwise** is a full-stack AI-powered blogging platform that allows users to generate smart blog content using Gemini API, upload images via ImageKit, and manage blogs with authentication and role-based access.

## 🚀 Features

- ✨ AI-generated blog creation using **Google Gemini API**
- 📸 Image upload and optimization using **ImageKit**
- 🔒 Secure **JWT-based authentication** for creators and admins
- 🧑‍💻 CRUD operations for blogs and category-based filtering
- 🌐 Fully responsive UI built with **React.js** and **Tailwind CSS**
- 🗂️ RESTful API integration with backend (**Node.js + Express**)
- 🌱 MongoDB-based persistent storage

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, Vite  
**Backend:** Node.js, Express.js  
**AI Integration:** Gemini API (free access)  
**Image Hosting:** ImageKit  
**Database:** MongoDB  
**Authentication:** JWT, Cookies  
**Deployment:** Vercel (frontend), Render/Other (backend)
